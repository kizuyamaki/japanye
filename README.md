# เว็บฝึกคำศัพท์ だい3か ことば (หน้า 128–129)

ในไฟล์ ZIP นี้มีให้เลือกใช้ 2 แบบ (เลือกอัปขึ้น GitHub แบบใดแบบหนึ่งได้เลย):

1. โฟลเดอร์ `1_code_separated/` (แบบแยกไฟล์)
   - `index.html`
   - `style.css`
   - `app.js`
   *วิธีใช้:* นำทั้ง 3 ไฟล์นี้ไปวางไว้ในโฟลเดอร์หลัก (Root) ของ Repository ใน GitHub

2. โฟลเดอร์ `2_code_single_file/` (แบบรวมไฟล์เดียว)
   - `index.html`
   *วิธีใช้:* นำไฟล์ `index.html` ไฟล์เดียวไปวางทับไฟล์เดิมใน GitHub ได้ทันที

## สิ่งที่แก้ไขเพิ่มให้แล้ว
- แก้บั๊กโค้ดหมวดตัวเลือก (`mcqSection`) ที่ทำให้สคริปต์หยุดทำงานในบางจังหวะ
- ครอบช่องพิมพ์ด้วย `<form>` แท้ + `inputmode="text"` + `-webkit-user-select: text` เพื่อให้ Android WebView / Google App / GitHub Pages เรียกแป้นพิมพ์มือถือ (รวมถึง Gboard เขียนด้วยมือ 手書き入力) ขึ้นมาได้ทันทีที่แตะ
- ไม่แปลงโรมันจิอัตโนมัติ รองรับการเขียนด้วยมือ (Handwriting) และทุกภาษาบนคีย์บอร์ดมือถือ
- เพิ่มตัวหน่วงเวลาหลัง `compositionend` (160ms) ป้องกันปุ่ม Enter ลั่นส่งคำตอบตอนกำลังจิ้มเลือกตัวคันจิที่เขียนด้วยมือ
